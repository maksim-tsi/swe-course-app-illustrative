# OpenCode agent adapters

These Markdown files are OpenCode-specific subagent definitions for the instructor's optional demonstrations. Their short bodies point to the canonical [portable role briefs](../../.agents/roles/README.md), the root [AGENTS.md](../../AGENTS.md), and current stage. This avoids maintaining five copies of the product requirements. OpenCode's discovery of this folder does not imply that Codex, Antigravity or GitHub CLI discovers it. The reviewer is configured read-only; other agents are scoped by their briefs and the instructor's bounded task.
